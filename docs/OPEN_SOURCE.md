# 开源与隐私边界

ChatMemory 是一个本地优先的聊天记忆整理器。

## 我们会做

- 导入用户主动选择的 `chat.json`、解密后的微信目录、HTML/MHT 归档
- 在本机建立统一时间线
- 提供搜索、标签、去重和本地持久化
- 使用开源协议发布代码

## 我们不会做

- 不读取微信进程内存
- 不提取微信本地数据库密钥
- 不自动解密加密微信数据库
- 不上传用户聊天内容
- 不绕过微信、macOS 或安卓安全机制

## 数据来源责任

导入文件必须来自用户自己账号的数据，或已经获得相关参与者明确同意的数据。

请勿使用本项目：

- 读取他人设备上的聊天数据
- 处理未脱敏的第三方隐私数据
- 规避微信、Apple、Google 或其他平台的安全机制
